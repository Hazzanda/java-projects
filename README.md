# Stock Reorder Checker

A simple Java console program that checks a product's stock level and tells you whether to reorder.

## What it does
- Asks for a product name, current stock, and minimum stock level
- Warns when stock is out or low and says how many packs to reorder
- Accepts negative quantities

## Sample run
```
Product name: Coca-Cola 50cl
Current stock quantity: 8
Minimum stock before reorder: 20
Reorder 12 packs of Coca-Cola 50cl soon. Current stock is below threshold.
```

## How to run
1. Open the folder in VS Code with the Java Extension Pack installed
2. Open the `.java` file and click **Run**
